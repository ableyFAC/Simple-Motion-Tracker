Welcome! 

This is a motion sensor made using the Arduino starter kit. It uses the ambient temperature of the user's environment to calculate the distance between the user and the closest object using an ultrasonic sensor.
An LCD is used to display both the temperature and the distance - both can be displayed via a button.
